# BASURA CERO

Los botaderos ilegales de basura crecen porque nadie los documenta.

Esta aplicación web permite a vecinos y a la unidad ambiental de la alcaldía registrar botaderos clandestinos con fotografía, descripción y ubicación exacta, además de gestionar su ciclo de vida mediante tres estados: **abierto**, **avisado** y **resuelto**.
